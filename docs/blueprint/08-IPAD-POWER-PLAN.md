# iPad power plan (on-device AI + full iPad feel)
Status: Plan only (Teacher-S, 2026-11-04). Not scheduled; 05-STAGES unchanged.
Device: iPad Air M3 (Apple Intelligence capable).

## Goal
Holding the iPad should feel powerful and enabling, never a cage. Full app power, iPad-native comfort, on-device AI where it truly helps.
Rule kept: every option still works on every platform; AI is a bonus layer, never the only way to do something.

## Step 1: Use what already works (no code)
- Writing Tools in every text box (remarks, notes, costume notes): proofread, rewrite, summarise.
- Make sure all text boxes are normal editable fields so Writing Tools appears.

## Step 2: Shortcuts bridge (small code)
- App offers "copy for Shortcut" / share sheet exports (e.g. today's register remarks, costume status).
- Ready-made Shortcuts that use Apple Intelligence: summarise remarks, draft a parent message, tidy notes.
- Result pasted back or saved to Notes.

## Step 3: iPad-native wrapper (bigger step)
- Thin native iPad app wrapping the web app, so it can use Apple's on-device model (Foundation Models).
- Possible magic moments (to be chosen with Q-questions before any build):
  - Auto-summary of a rehearsal's remarks.
  - Suggest note circles from what is typed.
  - Read a photographed list (costume list, notice) into items.
  - Spoken commands ("mark everyone present except ...").
- Same features get a non-AI fallback on web/desktop/Android.

## iPad feel (all steps)
- Keyboard shortcuts, trackpad hover, Pencil for drawing in Notes, split view, drag and drop.
- Big comfortable layout using the iPad's width, not a stretched phone.
